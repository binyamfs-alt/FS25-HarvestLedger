# FS25 Harvest Ledger

**Harvest Ledger** is a Farming Simulator 25 utility mod by **BinyamFS Modding** for tracking harvested fields and harvest results.

## Features

- Tracks player-owned field harvests
- Tracks contract field harvests separately
- Records harvested acreage and yield information
- Includes monthly ledger pages
- Automatically advances the month page at midnight
- Includes a movable harvest-ready HUD for player-owned fields
